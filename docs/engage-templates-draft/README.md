# Draft changes for `asticore/engage-templates`

This folder is a draft. Nothing here has been pushed to the templates repository. It follows that repo's own pattern (authoring sources under `templates/`, taxonomy in `taxonomy/`, spec in `docs/TEMPLATE_SPEC.md`, everything else generated by `npm run build`). It covers Task 38c in `docs/remaining-work.md`.

## What changes and why

The library today has two kinds, `section` and `page`. Engage's Templates area also holds site templates (header, footer, 404, search, archives, singles, sidebars), loops (a card drawn once per item) and popups. This draft adds those, bundles pictures in the repo, adds light and dark pairs, and adds the filters the Engage picker needs (type, category, industry, colour style, light or dark).

| # | Change | File in this folder |
| --- | --- | --- |
| 1 | New kinds `site-template`, `loop`, `popup` and a `siteKind` field | `spec-additions.md` |
| 2 | New category lists (`siteTemplates`, `loops`, `popups`) and colour sets | `taxonomy-additions.json` |
| 3 | Bundled pictures per item (`images/` folder, no third party links) | `spec-additions.md` section B |
| 4 | `theme: light \| dark \| both` plus `pairWith` (dark twin slug) | `spec-additions.md` section C |
| 5 | `parameters` block (for Engage Task 37c) | `spec-additions.md` section D |
| 6 | `schemaVersion` 2 and a CI validation step | `spec-additions.md` section E |
| 7 | Two filled examples: a shop archive with its loop, and a dark footer pair | `examples/` |
