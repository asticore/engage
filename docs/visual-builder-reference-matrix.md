# Visual builder reference matrix

Date: 22 Nov 2026. Part of Task 12 (31f) in docs/remaining-work.md.

This is a matrix of Engage's visual builder widgets and capabilities against twelve reference products: Elementor free, Elementor Pro, Premium Addons, Essential Addons, Happy Addons, Ultimate Addons, JetElements, The Plus, Bricks, Kadence Blocks, Spectra and Stackable. Built entries come from src/lib/elements/registry.ts and the "Built already" list in Task 9. Planned entries come from the Tasks 9, 10, 11, 12, 13, 14, 15, 18, 19 and 20 sections of docs/remaining-work.md.

Legend:
- Engage column: built, partial (Task N), planned (Task N) or not planned.
- Competitor columns: yes means the product is known to offer the feature. uncertain means not confirmed. It covers features that may be paid add-ons, features that are absent, and features this author did not check. uncertain is not a "no".

Important: entries marked uncertain must be checked against the live product before this matrix is used for any claim in marketing, sales or planning.
